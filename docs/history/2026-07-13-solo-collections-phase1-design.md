# SoloCollections 一期界面设计

## 目标

在 WoW 3.3.5a HD 客户端中新增一个独立的正式服风格收藏插件 `SoloCollections`，第一期只完成收藏入口、收藏主窗口、固定示例目录、筛选分页和真实 3D 预览。服务端新增独立的 `mod-ale` Lua 协议骨架，为第二期账号收藏、玩具代理法术和 `mod-transmog` 数据接入预留稳定边界。

## 已确认范围

- 采用“独立 AddOn + 独立服务端 Lua 协议骨架”方案。
- 视觉尽量 1:1 复刻用户提供的正式服收藏界面。
- 正式服 UI 源码只作为布局、交互和素材依据，不直接执行其现代 API。
- 正式服风格素材全部随 AddOn 放在 `Media`，不写入 `patch-enus-z.mpq`。
- 示例目录只使用当前 3.3.5 客户端已经存在的图标、物品、坐骑、小宠物和模型。
- 示例目录同时包含固定的已收集与灰色未收集状态。
- 所有预览都使用 3.3.5 原生 3D 模型控件，不使用静态截图。
- 不实现战斗宠物、传家宝、营区、真实解锁、拖入动作条、施法、数据库写入或幻化执行。

## 页面结构

底部使用四个正式服式主页签：

1. 坐骑
2. 小宠物
3. 玩具箱
4. 外观

“外观”包含“物品”和“套装”两个子页签，因此一期共有五个可验收页面。

### 坐骑

- 左侧为 24 条固定示例列表。
- 顶部显示收集进度、搜索框和已收集/未收集筛选器。
- 右侧显示名称、类型、说明和真实坐骑 3D 预览。
- 选择未收集坐骑时仍允许预览，但列表项和状态信息灰显。

### 小宠物

- 左侧为 24 条 3.3.5 非战斗小宠物示例。
- 右侧显示名称、类型、来源说明和真实小宠物 3D 预览。
- 不显示等级、品质、技能、队伍槽位、治疗或寻找对战控件。

### 玩具箱

- 使用正式服式三列图标目录和分页。
- 固定提供 36 条 3.3.5 趣味物品示例。
- 支持名称搜索、已收集/未收集筛选、星标和分页。
- 一期点击条目只显示图标、名称、来源和说明，不使用物品或施放法术。

### 外观：物品

- 顶部提供职业下拉、装备部位筛选、进度条和搜索框。
- 固定提供 48 件 3.3.5 装备示例。
- 使用网格展示外观；条目状态包含已收集和未收集。
- 选择条目后使用 `DressUpModel` 在当前角色模型上试穿。

### 外观：套装

- 左侧提供 8 套固定套装列表和职业筛选。
- 右侧显示套件部位图标行和当前角色真实 3D 试穿。
- 一期不保存、不应用、不删除搭配。

## 服务端 Lua 架构

源码文件：

```text
F:\1_projects\wow_projects\mod-ale\lua_scripts\solo_collections.lua
```

一期只定义：

- 协议前缀 `SC1`。
- 客户端 `HELLO` 请求。
- 服务端 `HELLO_ACK` 响应。
- 协议版本和功能位字段。
- 可关闭的 `SoloCollections.Enabled` 功能开关。

一期不创建 SQL、不查询收藏状态、不学习法术、不调用 `mod-transmog`。AddOn 未收到 `HELLO_ACK` 时自动进入演示模式，界面保持完整可用。

## 状态与数据流

固定目录保存在 AddOn 的 `Data` 文件中。`Core/Catalog.lua` 对五类数据提供统一的搜索、状态筛选、职业筛选、部位筛选、分页和计数接口。UI 页面只消费 Catalog 返回的视图模型，不直接读取其他页面的数据表。

```text
Data 固定示例
  -> Catalog 过滤与分页
  -> 当前页面按钮池
  -> 选中条目
  -> 真实 3D 预览
```

`SoloCollectionsDB` 只保存：

- 右下角入口按钮位置。
- 主窗口位置。
- 当前主页签和外观子页签。
- 搜索文本与筛选状态。
- 演示星标。

已收集/未收集状态属于固定测试数据，不允许在一期写回成真实收藏结果。

## 入口与主窗口

- 入口为右下角圆形收藏按钮，默认锚定 `UIParent` 的 `BOTTOMRIGHT`。
- 入口支持鼠标拖动、位置保存、提示文字和位置重置。
- 左键切换收藏主窗口显示状态。
- 主窗口延迟创建，首次打开时才创建页面和模型控件。
- 主窗口可移动、可关闭，并自动限制在屏幕范围内。
- 窗口尺寸按 1920×1080 设计，并在低分辨率下按 `UIParent` 尺寸缩放，不裁切关闭按钮、底部页签和搜索框。

## 3.3.5 兼容策略

- 不调用 `C_MountJournal`、`C_PetJournal`、`C_ToyBox`、`C_TransmogCollection` 等缺失 API。
- 不使用现代 Mixin、ScrollBox、DataProvider、SetAtlas、NineSlicePanel 或 ModelScene。
- 列表使用 3.3.5 `FauxScrollFrame` 或固定按钮池。
- 网格使用固定数量按钮复用与显式分页。
- 正式服 Atlas 素材拆成 3.3.5 可读取的独立 BLP/TGA 材质；需要时用 `TexCoord` 裁切。
- 坐骑和小宠物使用 `PlayerModel`/`DressUpModel` 支持的生物显示接口；外观使用 `DressUpModel:SetUnit("player")` 与 `TryOn`。
- 模型只为当前页面创建和显示，隐藏页面立即隐藏模型，避免持续渲染。

## 异常处理

- 缺失图标时显示 3.3.5 问号图标。
- 模型加载失败时保留文字信息并显示“无法预览”，不抛出 Lua 错误。
- 正式服风格素材缺失时退回纯色背景和 3.3.5 原生边框。
- 服务端 Lua 不存在、关闭或无响应时标记为演示模式，不弹阻断提示。
- 无搜索结果时显示明确空状态，不保留上一个条目的模型。
- 无效筛选值在登录或升级后自动恢复默认值。
- AddOn 通信内容必须带协议版本；未知消息和错误版本静默忽略并记录可选调试输出。

## 测试策略

自动检查覆盖：

- TOC 加载顺序、接口版本和 SavedVariables。
- 唯一全局命名空间和禁止的现代 API。
- 四个主页签和外观两个子页签。
- 固定示例数量、唯一 ID、必填字段和已/未收集混合状态。
- 搜索、筛选和分页的纯 Lua 数据契约。
- SC1 握手格式和演示模式回退。
- Media 文件引用存在且路径大小写一致。
- 源目录、客户端目录和服务端运行目录哈希一致。

游戏内手工检查覆盖：

- 右下角入口按钮打开、关闭、拖动和位置恢复。
- 五个页面切换、搜索、筛选、分页和空状态。
- 坐骑、小宠物、物品和套装真实 3D 预览。
- 已收集、未收集、选中和星标视觉状态。
- 1024×768、1920×1080 和当前 HD 客户端窗口分辨率。
- `/reload`、重新登录、关闭服务端 Lua以及同时启用既有插件。

## 一期验收标准

1. 登录后右下角出现收藏按钮，可拖动并记忆位置。
2. 点击按钮可靠打开和关闭收藏窗口。
3. 四个主页签和外观两个子页签均可切换。
4. 固定示例具有真实中文名称、图标、已/未收集状态和分页。
5. 搜索、已/未收集、职业和装备部位筛选有效。
6. 坐骑、小宠物和外观均显示真实 3D 预览。
7. 未收集条目灰显，但允许查看来源和预览。
8. `/reload` 和重新登录后位置、页签及筛选状态恢复。
9. 停用服务端 Lua 后 AddOn 仍以演示模式运行。
10. 与现有 AddOn 和模块同时启用时无全局变量冲突和 Lua 报错。
11. 目标分辨率下主要控件不越界、不裁切。
12. 一期不授予法术、不消耗物品、不写入收藏数据库。

## 后续阶段边界

第二期才实现账号级收藏表、真实拾取解锁、客户端状态同步、玩具代理法术和动作条拖放。服务端 Lua 稳定后可迁移到独立 AzerothCore C++ 模块，但保持 `SC1` 协议和 AddOn 页面接口兼容。
