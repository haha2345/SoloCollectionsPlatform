## 状态定义

| 标记 | 含义 |
|---|---|
| 已保留 | 当前本地代码仍在使用 |
| 已验证 | 经过客户端截图或用户测试确认 |
| 原型 | 已有接口或演示逻辑，但不是完整生产实现 |
| 待扩展 | 当前只覆盖有限种族、性别、数据或功能 |
| 禁用路线 | 已经证明不稳定，不应重新作为主实现 |

## 当前边界

- 插件：`addon/SoloCollections`
- 服务端桥：`server/ale/solo_collections.lua`
- 客户端镜头扩展：`client-extension/SoloCam`
- 测试与部署：`tools/collections`
- 客户端和 C++ 工具路径由开发者显式提供，不属于仓库。
- 构建缓存和临时资源放在仓库忽略的 `build` 或 `_work` 目录。
- 坐骑、小宠物、玩具的 Bridge 已有通信原型；完整服务端解锁和持久化仍需服务端 Lua/C++ 实现。
- 外观局部镜头目前重点验证的是人类女性。其他种族和性别不能直接套用现有参数。

## 给其他模型的执行规则

1. 先读目标页面对应文档，再读实际源码。
2. 不要把正式服 Lua API 直接复制到 3.3.5。
3. 一次只修改一个页面或一个装备部位。
4. 修改 DLL、MPQ 或客户端可执行文件前先确认客户端已退出。
5. 原始 `Wow.exe`、原始 MPQ 和用户已有文件必须保留备份。
6. 不把“演示收藏状态”描述成“服务端已完成”。
7. 武器显示优先遵循第 9 篇，禁止回退到已经失败的黑色模型路线。
8. 以仓库源码为唯一源头，不直接修改已部署副本后再反向复制。
