# 06 外观页和套装页

## 1. 页面目标

外观页使用正式服风格的多模型网格。普通装备不是显示物品图标，而是在每张卡片中创建角色模型、试穿对应物品，并用部位专属镜头裁切。套装页使用列表和右侧完整角色预览。

页面编排位于 `UI/Wardrobe.lua`，卡片模型生命周期位于
`UI/EzWardrobe/Model.lua`。

## 2. 物品页布局

固定参数：

```lua
ITEM_ROWS = 3
ITEM_COLUMNS = 6
ITEM_PAGE_SIZE = 18
ITEM_MODEL_WIDTH = 78
ITEM_MODEL_HEIGHT = 104
```

外观页与坐骑页使用相同的 `768` 宽度。物品网格保留 ezCollections 的
6 列 × 3 行尺寸和间距，当前阶段不重新设计卡片外观。

顶部过滤条提供职业和部位下拉框。主窗口公共区域提供搜索、收集状态过滤和进度条。

部位包括：头、肩、背、胸、手腕、手、腰、腿、脚、主手和副手。

## 3. 卡片组成

每张卡片包含：

- `DressUpModel`：所有装备卡片共用的模型控件。
- 护甲卡片使用玩家 `DressUpModel`、原生 `Undress/TryOn` 和 Transmorpher 的
  Classic 种族/性别/护甲部位构图。
- 主手/副手/远程卡片使用同一套玩家 `DressUpModel` 生命周期、SoloCam v11
  强制槽位 TryOn 桥和 Transmorpher 的武器子类构图；不使用固定 Creature。
- 独立 HitFrame：接收点击和 tooltip。
- 黑色背景。
- 1px 收藏状态边框。
- 2px 选中边框。
- 全卡片暖色 hover。
- 底部名称。
- 左上偏好星标。
- 右上小型“未收集”角标。

HitFrame 必须位于模型上方，不能依赖 3D 模型本身接收全部鼠标事件。

## 4. 已收集与未收集

正式服的区分重点是模型亮度、边框和文字，不是覆盖灰膜：

- 已收集：暖金细框、正常亮度、金色名称。
- 未收集：冷灰细框、模型适度变暗、灰色名称、小型角标。
- 偏好：金色星标。
- 选中：更亮的2px金边。
- 幻化室使用中：已写入当前选中槽、当前这件装备的外观卡另显示粉光边框（type 18 applied），与选中金边、已收藏对勾分开。

角标宽度要能完整显示“未收集”，禁止显示成“未收...”这种被裁切状态。

## 5. 物品模型流程

护甲和武器都采用 Transmorpher 的玩家 `DressUpModel` 路径。每条记录先经
`TransmorpherItemQuery` 等待物品缓存就绪，再进入 generation-safe 的共享队列；
驱动器每个 UI 帧最多处理一张有效卡片，过期页面或记录直接丢弃。

护甲严格按以下顺序渲染；`ClearModel` 与 `SetUnit` 必须分到相邻 UI 帧，
避免 build 12340 在 `0x008310AC` 读取已释放的动画轨道。`DressUpModel` 的
OnLoad 已经 `SetUnit("player")`，创建当帧或刚登录后不能立刻 `ClearModel`：

1. 先把模型 alpha 置 0，再 `SetPosition(0, 0, 0)`、`SetFacing(0)`，等一帧。
2. 下一帧 `ClearModel()`。
3. 再下一帧 `SetUnit("player")`，并恢复 Transmorpher 默认灯光、scale `1`、
   AutoDress、DoBlend 和 KeepModelOnHide 状态。
4. 再下一帧确认 `GetModel()` 非空后，按当前角色
   `raceFileName + sex + Armor + slot` 读取
   `Data/TransmorpherPreviewSetup.lua`。
5. 原生 `Undress()`。
6. 依次执行 `SetPosition(setup.x, setup.y, setup.z)`、
   `SetFacing(setup.facing)`、原生 `TryOn(itemId)`、
   `SetSequence(setup.sequence)`，再恢复 alpha。

幻化室首次打开再等 2 帧（`PLAYER_ENTERING_WORLD` 后 8 秒内等 6 帧）才
`Refresh` 预览。左侧大预览、幻化室套装卡和手册套装右侧不再走 `SafeDressUp`。实机物品卡能出
模型，是因为 EzWardrobe 在模型自己的后续帧做 `ClearModel` / `SetUnit` /
`Undress` / `TryOn`，**不等 `GetModel()`**。`Lab.PlayDressUp` 复制这条时序。
套装卡仍串行，一次一张。

武器使用相同 reset、查询、构图和序列顺序，但 `TryOn` 由 SoloCam v11 把
Transmorpher 的主手/副手装备栏转换到 build 12340 的内部模型槽；护甲不进入
DLL 强制槽位桥。

`OnUpdateModel` 只在 `GetModel()` 已就绪时恢复 Transmorpher 的动画 sequence，
不再重放位置、朝向或逐帧 `SetSequenceTime`。物品卡也不再加载
`EzCollectionsCamera.lua`，不使用 scale `10`、镜头缓存、镜头工作台或旧 M2
camera 路径。套装大预览和幻化室 `DRESSUP` 走 SoloCollections 自己的分帧
presenter，不再把 `ClearModel` 和 `SetUnit` 交给 NewEra 同帧执行。

18 个 `DressUpModel` 始终固定复用。记录未变化时只更新收藏状态、hover 和文字，
不重复完整换装。

## 6. 从套装页切回物品页

曾出现从套装部件点击进入物品页后，18张卡片全部显示玩家当前装备，翻页后才恢复。原因是隐藏状态下的 DressUpModel 丢弃临时 TryOn，而页面认为记录没有变化。

修复原则：

1. 切换到物品页时使相关模型 generation 失效。
2. 清空 `scRecordId` 或强制队列重新换装。
3. 显示 items panel 后再执行 `SetUnit/TryOn`。
4. 不依赖翻页触发恢复。

## 7. 职业和部位过滤

职业过滤同时支持：

- 直接 `classToken`。
- 3.3.5 `classMask` 位判断。

部位过滤使用稳定的内部键，不用中文标签作为逻辑值。`INVTYPE_ROBE` 与胸部同组；盾牌、held in off-hand 和副手武器进入 OFFHAND。

修改职业或部位后：

1. 页码回到1。
2. 清理当前选择。
3. Catalog 重新查询。
4. 更新进度条。
5. 只重绑18个卡片。

## 8. 套装页

套装页结构：

- 左侧8条固定复用列表行。
- 左侧列表使用极窄玻璃质感图标框，不复用宽黄色收藏边框。
- 左侧列表支持鼠标滚轮逐行滚动、可拖动滚动条，并保留翻页按钮作为备用操作。
- 右侧九宫格预览框。
- 完整 `DressUpModel`。
- 套装名称居中显示在部件卡片上方，职业和收集进度显示在底部。
- 最多8个部件图标；图标整体动态居中，使用1px物品品质色边框和轻微玻璃高光。
- 职业下拉框位于右上方，首次进入套装页时默认选择当前角色职业。

套装部件必须按装备顺序 TryOn，不能依赖 Data 中任意顺序。当前代码使用 `STABLE_SLOT_ORDER`，在物品信息尚未缓存时使用 `SET_INDEX_FALLBACK_ORDER`。

点击部件图标可显示物品 tooltip；后续若实现跳转，应先设置物品页过滤/选择，再显示物品页并强制刷新目标卡片。

## 9. 套装预览交互

- 左键拖动改变 rotation。
- 滚轮使用有限区间调整 position/zoom。
- 重置视角恢复固定 rotation 和 position。
- 页面隐藏时清除拖动和 OnUpdate 状态。

## 10. 验收标准

- 外观页宽度与坐骑页一致，均为 768。
- 一页固定18张 78×104 卡片，尺寸和间距稳定。
- 边框接近正式服细框，不再占据大量模型区域。
- hover 覆盖整张卡片。
- 未收集文字完整。
- 每个普通装备显示对应部位，不是全身或统一头部。
- 九个护甲部位均使用 Transmorpher Classic 构图，翻页和武器往返不切回旧
  ezCollections 镜头或逐帧冻结路径。
- 从套装切回物品页无需翻页即可恢复正确装备。
- 套装部件按稳定顺序试穿。
- 套装部件卡片按实际物品品质显示细边框，缓存完成后自动补齐品质色。
- 左侧列表在行、空白区和滚动条上都可用鼠标滚轮浏览。
- 首次进入套装页默认显示当前角色职业，仍可手动选择全部职业或其他职业。
- 翻页不会持续创建新的模型控件。
- 主手、副手和远程自动切换到 Transmorpher 玩家模型路径，并使用对应的
  Classic 武器构图。

## 11. 幻化室应用与游戏内模型

幻化室大预览的 `TryOn` 只是本地草稿。点应用后由 `Y APPLY` 同时写入：

- `character_sc_transmog`（type 18 投影，重登后预览和方案用）
- `custom_transmogrification`（物品 FakeEntry，驱动 `SetVisibleItemSlot`）

游戏内角色模型只看 FakeEntry。隐藏外观的库值仍是 `HIDDEN_ITEM_ID=1`，但可见
槽必须写成 `0`；写成 `1` 时 3.3.5 客户端没有该物品，会继续显示真实装备。

已收藏外观只校验目标装备的槽位/护甲或武器族，不再用源物品 `AllowableClass`
挡住当前职业。预览成功、应用返回 `CLASS_RESTRICTED` 时，库里不会留下这条外观。

外观跟**装备实例**走，不跟槽位自动换装。同一件卸下再穿回来仍显示 FakeEntry；
换另一件就显示那件自己的外观或真实模型。幻化室预览在换装后若 itemId 对不上
上次应用，不再读 type 18，避免谎报旧外观。

`Y QUOTE`/`APPLY` 的 `U.copper` 按每个实际改变的非隐藏槽位计价：
`max(外观源物品卖价, 1金) × ScaledCostModifier + CopperCost`。隐藏和清除免费。
已应用幻化（含隐藏）在无待定时，右键槽位或点原物卡撤销角标都先弹确认，确定后
才走 `Y CLEAR`，删除该装备实例的 FakeEntry 并清 type 18，角色显示原物。原物卡钉
在隐藏外观后面，未收藏或未搜到也会出现。其余外观已收集排在未收集前面。方向键
选到原物卡只写入草稿，不立刻清除。套装预设用同一条报价；type 18
Ready 后套装应用也走 `Y APPLY`。客户端不得估算金额。不提供专精独立应用。

幻化室大预览和套装卡共用 `PlayDressUp` 分帧 `ClearModel` / `SetUnit` /
`Undress` / `TryOn`，不等 `GetModel()`。左侧预览另存 `scRotation` / `scZoom`，
拖转、滚轮和重置镜头换装后仍恢复；套装卡不跟这套镜头。方向键在物品 6 列 /
套装 4 列网格移动选择并翻页。2026-08-16 上述幻化室交互已实机验收通过。

幻化槽位 tooltip：品质色原装备名 + 粉色「幻化为:」/「你将要幻化为:」+
粉色外观名，不要物品属性。名称优先来自物品链接；3.3.5 上 link 未缓存
不等于空槽，应用 texture / count / `equippedBySlot` 判断穿着，标题可回退
到「物品 <id>」或槽位名。官方空槽句只用于槽里确实没装备，未幻化不是空槽、
也不写「幻化为:」。空槽按军团关死：不能 `SetDraft`、不进 `Y APPLY`，卸下
装备会清该槽草稿；点卡提示「该装备栏里没有装备物品。」套装预设仍跳过
没穿着的部件。未收藏待定不能报价或应用，点应用提示「你尚未收集此外观。」
其它不能提交的原因（隐藏未就绪、不兼容、金币不足、服务端拒绝）同样先判断再提示，
不要弹出 0 铜确认。有待定时替换已应用行，两行不并存。隐藏条目写「隐藏」。

收藏室跨甲只读服务端 `SoloCollections.Transmog.MixedArmor`（`same` /
`lower` / `any`，默认 `any`）。物品页护甲槽有甲种下拉；`AUTO` 查询时解析成
当前职业甲，手选 `ALL` 看全部甲。开窗时若职业仍是 `ALL` 则写成当前职业，
不覆盖玩家手选。套装列表已收集一桶再接未收集一桶，不用 `table.sort`。
方向键/翻页/ESC 用 `SetOverrideBinding`，不整窗 `EnableKeyboard`，避免吞
WASD。衬衣、战袍小卡走 ezCollections 同款玩家 `DressUpModel` + `Undress` /
`TryOn`，镜头用 Transmorpher `Armor.Shirt` / `Armor.Tabard`。枪/弓/弩小卡走
Transmorpher 远程构图（`Ranged` + Bow/Gun/Crossbow）和 SoloCam 槽位 TryOn，
不再当护甲卡。左侧大预览仍 `PlayDressUp`。应用成功后若试穿清单没变，左侧
不再 `ClearModel`；换装步进挂在宿主帧上，避免 `DressUpModel` 在
`ClearModel` 后停掉 OnUpdate。手册物品页不显示枪/弓/弩卡，武器下拉也不列
这三项。手册套装右侧预览走 `Lab.PlayDressUp`，不等 `GetModel()`。
`UNIT_MODEL_CHANGED` 不再取消套装预览：3.3.5 上 `SetUnit("player")` 会触发
该事件，再 `Refresh` 会只留下第一套或弹出红字。

套装成员以 `ItemSet.dbc` 清单为底，再按现有件中文名最长公共前缀补缺的
腕/腰/鞋/背。不新建、不回收套装 ID。鞋名与套装名不同的（如 T7
天灾苦痛）补不上。误匹配用 `catalog/source/overrides/sets.json` 排除。
