# 06 外观页和套装页

## 1. 页面目标

外观页使用正式服风格的多模型网格。普通装备不是显示物品图标，而是在每张卡片中创建角色模型、试穿对应物品，并用部位专属镜头裁切。套装页使用列表和右侧完整角色预览。

实现文件：`UI/Wardrobe.lua`。

## 2. 物品页布局

固定参数：

```lua
ITEM_ROWS = 3
ITEM_COLUMNS = 6
ITEM_PAGE_SIZE = 18
ITEM_MODEL_WIDTH = 78
ITEM_MODEL_HEIGHT = 104
```

外观页与坐骑页使用相同的 `768` 宽度。物品网格保留 ezCollections 的
6 列 × 3 行尺寸和间距，当前阶段不重新设计卡片外观。

顶部过滤条提供职业和部位下拉框。主窗口公共区域提供搜索、收集状态过滤和进度条。

部位包括：头、肩、背、胸、手腕、手、腰、腿、脚、主手和副手。

## 3. 卡片组成

每张卡片包含：

- `DressUpModel`：所有装备卡片共用的模型控件。
- 护甲卡片使用当前玩家模型、`SetUnit("player") + TryOn` 和 scale `10`。
- 主手/副手卡片使用同一个固定预览 Creature、`TryOn` 和 scale `1`，不按玩家
  种族/性别重新标定武器镜头。
- 独立 HitFrame：接收点击和 tooltip。
- 黑色背景。
- 1px 收藏状态边框。
- 2px 选中边框。
- 全卡片暖色 hover。
- 底部名称。
- 左上偏好星标。
- 右上小型“未收集”角标。

HitFrame 必须位于模型上方，不能依赖 3D 模型本身接收全部鼠标事件。

## 4. 已收集与未收集

正式服的区分重点是模型亮度、边框和文字，不是覆盖灰膜：

- 已收集：暖金细框、正常亮度、金色名称。
- 未收集：冷灰细框、模型适度变暗、灰色名称、小型角标。
- 偏好：金色星标。
- 选中：更亮的2px金边。

角标宽度要能完整显示“未收集”，禁止显示成“未收...”这种被裁切状态。

## 5. 普通装备模型流程

普通部位使用 `DressUpModel`：

1. `ClearModel()`。
2. `SetUnit("player")` 建立当前角色种族和性别。
3. 解析 `itemLink`，没有缓存时回退到 `item:itemId`。
4. `TryOn(itemString)`。
5. 等待模型异步完成。
6. 从 `Data/EzCollectionsCamera.lua` 读取 ezCollections Classic 的
   `(race, sex, slot)` 镜头元组并应用位置、朝向和动画。
7. 在 `SetUnit/SetCreature`、`TryOn` 和 `OnUpdateModel` 后分别补用同一镜头；
   只有原生位置/朝向调用成功才标记本代镜头完成。
8. 将动画固定在第 0 帧，使网格中的模型保持静态。

现行卡片不得调用旧 `M2Camera.Reset/SetCamera(0)`，避免 SoloCam 旧路线覆盖
ezCollections 的模型空间镜头。

`SetUnit/TryOn` 可能在首帧后再次重建模型并还原原生全身视角，因此 `OnUpdateModel` 要为同一 generation 重新排队应用镜头。

不要在模型记录未变化时重复执行完整换装。当前逻辑使用 record ID、profile 和 render kind 判断是否 unchanged。

## 6. 从套装页切回物品页

曾出现从套装部件点击进入物品页后，18张卡片全部显示玩家当前装备，翻页后才恢复。原因是隐藏状态下的 DressUpModel 丢弃临时 TryOn，而页面认为记录没有变化。

修复原则：

1. 切换到物品页时使相关模型 generation 失效。
2. 清空 `scRecordId` 或强制队列重新换装。
3. 显示 items panel 后再执行 `SetUnit/TryOn`。
4. 不依赖翻页触发恢复。

## 7. 职业和部位过滤

职业过滤同时支持：

- 直接 `classToken`。
- 3.3.5 `classMask` 位判断。

部位过滤使用稳定的内部键，不用中文标签作为逻辑值。`INVTYPE_ROBE` 与胸部同组；盾牌、held in off-hand 和副手武器进入 OFFHAND。

修改职业或部位后：

1. 页码回到1。
2. 清理当前选择。
3. Catalog 重新查询。
4. 更新进度条。
5. 只重绑18个卡片。

## 8. 套装页

套装页结构：

- 左侧8条固定复用列表行。
- 左侧列表使用极窄玻璃质感图标框，不复用宽黄色收藏边框。
- 左侧列表支持鼠标滚轮逐行滚动、可拖动滚动条，并保留翻页按钮作为备用操作。
- 右侧九宫格预览框。
- 完整 `DressUpModel`。
- 套装名称居中显示在部件卡片上方，职业和收集进度显示在底部。
- 最多8个部件图标；图标整体动态居中，使用1px物品品质色边框和轻微玻璃高光。
- 职业下拉框位于右上方，首次进入套装页时默认选择当前角色职业。

套装部件必须按装备顺序 TryOn，不能依赖 Data 中任意顺序。当前代码使用 `STABLE_SLOT_ORDER`，在物品信息尚未缓存时使用 `SET_INDEX_FALLBACK_ORDER`。

点击部件图标可显示物品 tooltip；后续若实现跳转，应先设置物品页过滤/选择，再显示物品页并强制刷新目标卡片。

## 9. 套装预览交互

- 左键拖动改变 rotation。
- 滚轮使用有限区间调整 position/zoom。
- 重置视角恢复固定 rotation 和 position。
- 页面隐藏时清除拖动和 OnUpdate 状态。

## 10. 验收标准

- 外观页宽度与坐骑页一致，均为 768。
- 一页固定18张 78×104 卡片，尺寸和间距稳定。
- 边框接近正式服细框，不再占据大量模型区域。
- hover 覆盖整张卡片。
- 未收集文字完整。
- 每个普通装备显示对应部位，不是全身或统一头部。
- 从套装切回物品页无需翻页即可恢复正确装备。
- 套装部件按稳定顺序试穿。
- 套装部件卡片按实际物品品质显示细边框，缓存完成后自动补齐品质色。
- 左侧列表在行、空白区和滚动条上都可用鼠标滚轮浏览。
- 首次进入套装页默认显示当前角色职业，仍可手动选择全部职业或其他职业。
- 翻页不会持续创建新的模型控件。
- 主手和副手自动切换到固定预览 Creature，并使用 ezCollections 武器镜头。
