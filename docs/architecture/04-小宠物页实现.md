# 04 小宠物页实现

## 1. 范围

本页只实现 3.3.5 已存在的非战斗小宠物（companions），不实现正式服 Pet Journal 的战斗宠物等级、品质、技能和队伍。

实现文件：`UI/Pets.lua`。其视觉结构与坐骑页一致，数据和 Bridge 请求独立。

## 2. 页面组成

- 左侧带边框的 FauxScrollFrame 列表。
- 图标、名称、来源、收藏状态和偏好星标。
- 右键召唤/偏好菜单。
- 右侧图标、名称、来源、描述、收藏状态。
- 右侧 `PlayerModel` 宠物预览。
- 召唤、设置偏好和重置视角按钮。

## 3. 数据字段

小宠物记录建议包含：

```lua
{
    id = 1,
    creatureId = 1234,
    name = "宠物名称",
    icon = "Interface\\Icons\\...",
    source = "来源",
    description = "描述",
    collected = false,
    favorite = false,
}
```

`creatureId` 用于 `PlayerModel:SetCreature()`。收藏 ID 和 creature ID 不应默认视为同一个字段。

## 4. 列表与交互

复用坐骑列表的固定可见行方案：

1. Catalog 查询 `PETS`。
2. `FauxScrollFrame_Update()`。
3. 按 offset 绑定可见记录。
4. 左键选择。
5. 右键打开菜单。
6. 行和滚动区都支持滚轮。

未收集宠物禁止召唤和设置偏好。菜单禁用只是视觉反馈，执行函数仍要再次校验。

## 5. 模型预览

宠物模型与坐骑模型使用相同的异步保护：

- 每次切换增加 `scModelGeneration`。
- 废弃旧 generation 的延迟任务。
- 先 `ClearModel()` 和重置视角。
- 调用 `SetCreature(record.creatureId)`。
- 等待模型准备后设置基础缩放和 facing。
- 加载失败显示“无法预览”。

模型支持：

- 左键拖动旋转。
- 滚轮缩放。
- 重置视角。

缩放必须基于固定 `scBaseScale`，不能累计。

## 6. Bridge 调用

- 模型准备：`SC.Bridge.RequestPetModel(petId, callback)`。
- 召唤：`SC.Bridge.SummonPet(petId, callback)`。

Bridge 返回的宠物 ID 必须与 pending 请求一致。不要接受服务端返回的任意 creature ID 并直接加载。

## 7. 与坐骑页共享代码

当前仓库存在 `UI/CompanionBase.lua`，但坐骑和宠物页仍有部分重复实现。后续重构可以抽取：

- 左侧列表创建。
- FauxScrollFrame 滚动。
- 右键菜单骨架。
- 模型拖动、缩放、重置。
- generation 任务调度。
- 收藏状态和偏好按钮逻辑。

不要为了去重而把坐骑和宠物的业务字段强行统一。共享框架，保留各自的模型解析和 Bridge 方法。

## 8. 验收标准

- 页面文案始终使用“小宠物”，不出现战斗等级和技能。
- 列表可以连续滚动并显示范围提示。
- 未收集宠物不能召唤或偏好。
- 已收集宠物可以通过按钮和右键菜单召唤。
- 切换宠物不会累积缩放。
- 模型旋转、缩放、重置正常。
- 搜索、已收集/未收集过滤和进度条正确。
- Bridge 超时不会让页面永久处于等待状态。
