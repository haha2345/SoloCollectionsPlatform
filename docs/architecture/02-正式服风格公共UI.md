# 02 正式服风格公共 UI

## 1. 设计目标

3.3.5 没有正式服收藏日志模板，因此需要复用旧客户端可用的 Frame、Texture、StatusBar、EditBox 和 Dropdown，自行拼出正式服的结构。参考正式服时只复刻布局、层级和交互，不复制依赖新 API 的代码。

## 2. 主窗口结构

主入口是 `UI.CreateCollectionsFrame()`：

```text
主窗口
├─ 左上圆形分类图标
├─ 顶部标题
├─ 收藏数/总数
├─ 进度条
├─ 搜索框 + 过滤器
├─ 外观页专用“物品/套装”标签
├─ 内容宿主
└─ 窗口下方独立主标签
```

当前主窗口大小和锚点由 `CollectionsFrame.lua` 维护。内容宿主从窗口顶部约 122 像素开始，底部为悬挂标签保留空间。收藏手册只包含坐骑、小宠物、玩具、头衔和外观；幻化使用独立的 `WardrobeFrame`（`UI.CreateTransmogFrame()`，965×606，无底部标签）。

幻化室复刻 ezCollections 2.2 / Legion `WardrobeFrame` 几何（见 `_work/retail-wardrobe-extract/LAYOUT.md`）：

```text
WardrobeFrame 965×606
├─ 标题「幻化」与关闭按钮
├─ 左侧 WardrobeTransmogFrame：300×495 @ TOPLEFT 4,-86
│  ├─ 方案下拉 TOPLEFT (-14, 28) 宽 188；账号 type 19，最多 10 套；本机 SavedVariables 不当权威
│  ├─ 294×488 预览：拖转 / 滚轮 / 左下重置镜头
│  ├─ 槽位 43×43（远程 BOTTOM 90, 45）；HideVisual 为保留 ID 2，type 18 Ready 后可写入
│  ├─ 主/副手附魔小槽 27×27 CENTER -26/-203 与 27/-203，禁用
│  ├─ 武器左右手警告条：模型底 BOTTOM y=5 高 46，选主手/副手时淡入
│  └─ 费用铬 + SmallMoneyFrame（只用最近一次 U.copper）/ 应用；脏槽一次 Y APPLY；无专精钮
└─ 右侧 CollectionFrame：662×606 @ TOPRIGHT (0, 0)
   ├─ ItemsTab TOPLEFT (8, -28)；SetsTab 紧贴其右
   ├─ 进度条相对 ItemsTab TOPLEFT (195, -11)
   ├─ 搜索 115×20 在 CollectionFrame 顶栏；银钮「来源」LEFT of search (2, -1)
   ├─ 物品页：银钮「来源」= 已收集/未收集 + 粗分来源；套装页银钮「过滤器」= 已收集/未收集
   ├─ 套装职业下拉：大理石 inset TOPRIGHT (-32, -25)，宽 140；与手册共用 `classToken`
   ├─ 武器子类 `WeaponDropDown`：大理石 inset TOPRIGHT (-32, -25)，宽 140；仅主手/副手/远程
   └─ 大理石 inset TOPLEFT (4, -60)，宽高显式 652×541；物品卡 TOP (-235, -71)
```

3.3.5 不能可靠地让单张 `UI-Background-Marble` 按 `SetHorizTile` 铺满大框，只会留下一块约 256px 的竖带。`Ez:UpdateInset` 改为按原生 256px 拼贴多张纹理。左侧种族背景关掉拼贴，并用 `SetTexCoord(0, 294/512, 0, 494/512)` 只取 `TransmogBackground*` 左上 294×494；这些 TGA 是 512×512，右侧/底部是空像素，整图 0–1 会看起来半边有景、半边黑。

进度条必须贴 ItemsTab，不能锚到右侧面板顶上。网格和 inset 从 y=-60 起，不得盖住标题栏/进度条。

## 3. 公共组件

## 3. 公共组件

### 九宫格和三段式纹理

边框不能把一张纹理直接拉满。`UI.ApplyNineSlice()` 将四角、四边和中心拆开；搜索框、标签和进度条适合使用三段式结构，固定两端，只拉伸中段。

### 底部标签

使用 `UI.CreateRetailBottomTab()`：

- 标签独立悬挂在主窗口下方。
- 未选中状态有深色实体填充。
- 选中状态显示金色渐变。
- 有完整边框、文字和悬停高亮。
- 相邻标签之间保留间距，不连接成一条透明栏。

切页统一调用 `UI.SetMainTab(key)`，不要直接在按钮回调中散落 `Show/Hide`。

### 搜索框

使用 `UI.CreateRetailSearchBox()`：

- 左侧搜索图标。
- 无输入时显示占位文字。
- 有输入时出现清除按钮。
- `OnTextChanged` 只修改查询并刷新活动页。
- 不在每次键入时重建整个主窗口。

### 过滤器

玩具、头衔等页仍用 `UI.CreateFilterPopup()` 自制弹窗。外观相关页在按钮上挂
`UIDropDownMenuTemplate`，点击走 `ToggleDropDownMenu(1, nil, dropDown, self, 74, 15)`，
箭头默认朝下。只要按钮设置了 `SetWardrobeDropDown`，就不要再看 `mainTab` 才决定
走下拉。

- 收藏手册外观页：一级为已收集 / 未收集，二级「来源」为掉落 / 任务 / 商人 / 专业。
- 独立幻化室物品页：按钮文案是「来源」，一级为已收集 / 未收集，以及掉落 / 任务 /
  商人 / 专业（含全部勾选 / 全部取消）。不放偏好；未收藏外观在「未收集」勾选时可预览，
  应用按钮仍按是否已收藏禁用。
- 幻化室套装页：银钮文案是「过滤器」，菜单只有已收集 / 未收集，不放来源和偏好。
  职业下拉与手册同一套 `Identity.GetClassFilterOptions()`，写入 `filters.classToken`。
  本会话第一次打开任一套装页时默认当前职业；之后「全部职业」两边都保留。
  套装查询固定 `slot=ALL`，不带当前幻化槽、护甲或武器过滤。
- 来源数据读 `GeneratedWardrobeAcquisitionSources.itemSources[itemId].kind`。
  `quest`→任务，`vendor`→商人，`crafted`→专业，`drop`/`gameobject`/`container`→掉落。
  无记录的外观 fail-open，不因来源被藏。这是粗分，不是军团 6 类来源。
- 勾选状态存在 `filters.appearances.hiddenSources`；隐藏某类时该 key 为 `true`。
- 幻化室搜索/来源钮挂在右侧 CollectionFrame 的 210×22 宿主上，不要缩成 1×1。
  主窗 `SetClampedToScreen(true)`，避免 1280 宽下按钮被推出屏外。
- 武器子类是独立 `UIDropDownMenu`，不要塞进「来源」菜单。父级是大理石 inset
  （军团 `ItemsCollectionFrame`），锚点 TOPRIGHT (-32, -25)，`SetWidth(140)`。
  只在物品页的主手/副手/远程显示；套装页和护甲槽隐藏。主手选项排除弓/枪/弩/
  投掷/魔杖（那些在远程槽）。当前职业 `Identity.GetWeaponTypes` 没有对应子类时
  隐藏下拉，查询用 `AUTO`。只有一个子类时显示但禁用，和军团一致。
  勾选写入 `filters.weaponType`，与手册共用。

弹窗和下拉应在窗口隐藏或切页时关闭；勾选来源刷新列表时不要关掉菜单。

幻化室物品页第 1 张是 HideVisual「隐藏外观」（保留 collectionId `2`），第 2 张钉
当前槽位穿着的原物外观，不受已收集/来源/搜索过滤影响，避免起步装夹在几百页里
找不到。其余卡片先拆已收集、再接未收集，不用 `table.sort`，避免 3.3.5 在大门类上排乱。选中隐藏后，左侧槽位加黑罩，预览对该槽 `Undress` 再试穿其余部位。type 18 Ready 后可写入
当前角色；成功后草稿清空，预览改读 type 18（`2` 继续隐藏该槽）。type 18 未
就绪时隐藏只留本地预览，应用按钮弹出说明后中止。主/副手附魔小槽按军团几何
画出并禁用，不假装能预览或提交附魔。

清除待定、切回当前装备、覆盖/删除方案、载入方案覆盖草稿，一律用可见
`StaticPopup`，不要再用隐藏状态字做两次点击确认。弹窗失败时回落到聊天框和
`UIErrorsFrame`，确认不能 silently 消失。

物品卡和套装卡的收藏态都不能写在 DressUpModel 的 alpha 上：`Present()` 会把模型
透明度重设为 1。未收藏用 hit 层黑罩 + 「未收集」角标，已收藏用勾选角标，边框仍
走 collected / uncollected atlas。隐藏外观卡不显示这两枚角标。
已应用到当前装备的外观卡（含已写入的隐藏外观）另显示粉光「使用中」边框，不占用已收藏对勾；仅本地草稿选中仍用金边。
该槽已幻化成别的外观时，穿着原物对应的那张卡显示撤销角标；左键或槽位右键恢复原装备都先弹确认，确定后再 `Y CLEAR`。方向键不走这条清除。

幻化室打开且搜索框没有焦点时，方向键按军团规则在物品 6 列 / 套装 4 列网格移动选择并翻页；`PAGEUP` / `PAGEDOWN` 只翻页。3.3.5 没有 `SetPropagateKeyboardInput`，键盘挂在 `WardrobeFrame` 的 `OnKeyDown`。

左侧大预览支持拖转、滚轮缩放和重置镜头；换装后保留当前朝向和距离，不要在 `PlayDressUp` 里写死回默认。重置镜头是预览左下角独立按钮，不要占用方案旁的「撤销所有待定」黄圈。不提供专精独立应用，也不再画那颗禁用的专精钮。

2026-08-16 实机验收通过：原物钉在第 2 张、已收集先于未收集（含已幻化槽）、撤销角标需确认、方向键选卡翻页、左侧拖转/滚轮/重置镜头。

幻化室音效对齐 ez 2.2，不调用军团 `SOUNDKIT.UI_TRANSMOG_*`。开窗/关窗播
`UI_EtherealWindow_Open/Close.wav`（无 `SoloCollections_EzUI` 时回落到
`igCharacterInfoOpen/Close`）。Apply 只在 SC2 整次成功后播
`UI_Transmogrify_Apply.wav`，不要在点击应用时先播。右键撤销槽或确认清除全部待定
播 `UI_Reforging_Restore.wav`。点槽用 `igSpellBookSpellIconPickup`，点卡片用
`igMainMenuOptionCheckBoxOn`。

物品卡 tooltip 显示目录里的粗分来源种类和 `acquisition` 文本；没有记录时不编造
首领/副本。套装卡只显示已有的 `source` 或 `presentation` 标签。

待定槽在粉光之外按军团播紫蚂蚁：`PurpleIconAlertAnts` 44×44，`AnimateTexCoords`
256/48、22 帧。3.3.5 没有该全局函数，用本地实现；素材缺失时不显示蚂蚁。

军团点应用：费用始终在左侧 MoneyFrame（`C_Transmog.GetCost`，0 铜也显示）；
只有 `GetApplyWarnings()` 非空才弹 `TRANSMOG_APPLY_WARNING`，没有警告就直接提交。
本插件可提交的应用一律先弹确认，并用 3.3.5 `hasMoneyFrame` 提示费用。左侧费用条
用 `SmallMoneyFrameTemplate` + `Lab.UpdateQuotedMoney`。3.3.5 `STATIC` 会折叠真正
的 0 铜报价，只有这时才再显示 `CopperButton=0`。1 金及以上必须交给
`MoneyFrame_Update` 显示金币，不能再强制铜币，否则会把 10000 铜画成 0。铬仍是
三段 `MoneyFrame.tga`。金额只来自最近一次 `U.copper`，禁止客户端估算。关窗关掉
弹窗。

选主手或副手时，预览底部显示 ez 的左右手警告条（橙 Search 纹理淡入，文案
「武器可能会出现在错误的手中」）。远程槽和护甲槽淡出隐藏。这不是附魔槽的
`invalidWeapon` 标志。

### 进度条

使用 `UI.CreateRetailProgressBar()`：

- holder 负责整体尺寸。
- StatusBar 的真实内容尺寸必须小于外框。
- 边框单独覆盖在前景层。
- 数字文字锚定到 StatusBar 中心。
- `SetProgress(collected,total)` 处理 total 为 0 的情况。

这样可以避免绿色填充越过边框，以及边框被横向拉伸。

### 收藏数量框

`UI.CreateCollectionCount()` 显示分类名称和数量。页面刷新时同时更新数量框和进度条，不能只更新绿色条而漏掉数字。

## 4. 左上圆形图标

正式服图标由三层组成：

1. 实际分类图标。
2. 圆形裁切/背景。
3. 完整金色圆环覆盖层。

图标与圆环必须同心，圆环尺寸略大于图标。不能使用方形图标加普通方框模拟。现有基础资源位于：

- `Media/Icons/mount-portrait.tga`
- `Media/Icons/launcher.tga`
- `Media/Icons/WardrobeSlots/slot-atlas.tga`
- `Media/Icons/WardrobeSlots/round-highlight.tga`

这些文件均由基础 AddOn bundle 发布；其格式、Hash 和来源由
`Media/assets.json` 约束。可选皮肤不得成为默认圆形图标或启动按钮的隐式
依赖。

## 5. 启动按钮

`UI.CreateLauncher()` 创建屏幕右下角两个入口：

- 收藏按钮默认锚定 `BOTTOMRIGHT -28, 150`，左键切换收藏日志。
- 幻化按钮默认锚定 `BOTTOMRIGHT -82, 150`，左键切换独立幻化室。
- 左键拖动时分别移动按钮，位置写入 `launcher` / `transmogLauncher`。
- `SetClampedToScreen(true)` 防止拖出屏幕。
- `UI.ResetPositions()` 与 `/sc reset` 恢复默认位置。

按钮使用正式服收藏/幻化图标和金色圆环，不使用临时背包图标。

正式服 `WardrobeFrame` 的左上肖像点击会打开收藏手册；本插件同样把幻化窗肖像作为返回收藏的入口。两个窗口互斥显示。

## 6. 视觉状态约定

| 状态 | 推荐表现 |
|---|---|
| 已收集 | 正常亮度、金色名称或暖金细框 |
| 未收集 | 降低亮度、冷灰细框、可选小型“未收集”角标 |
| 已选中 | 2px 金黄色边框 |
| 使用中 | 幻化室物品卡：粉光 current-transmogged 边框，仅 type 18 已写入当前装备时显示 |
| 鼠标悬停 | 全卡片轻微暖色 ADD 高亮 |
| 偏好 | 左上角金色星标 |
| 不可操作 | 按钮禁用并在 tooltip 说明原因 |

禁止用覆盖模型主体的大面积灰色矩形表现未收集，它会让卡片看起来像加载失败。

## 7. 新页面接入步骤

收藏手册内页：

1. 创建页面 Frame 并填满 content host。
2. 设置 `scCategory`。
3. 实现 `Refresh()`、`SyncFilters()`、可选 `ClearSelection()`。
4. 在 `CollectionsFrame` 页面表和标签表注册。
5. 为页面设置标题、图标、数量名称。
6. 让搜索和过滤调用活动页方法。
7. 切页时关闭旧页面菜单并停止旧页面模型任务。

幻化室不是手册标签。它由 `UI.CreateTransmogFrame()` 创建独立 `WardrobeFrame`，由 `SoloCollectionsTransmogLauncher` 或 `/sc transmog` 打开。

## 8. 幻化室权威边界

幻化室脏槽走一条 `Y APPLY`，费用只显示最近一次 `U.copper`。服务端按每个实际
改变的非隐藏槽位用外观源物品卖价计价（至少 1 金）；隐藏和清除为 0。套装预设
先 `Y QUOTE`，type 18 Ready 后也走 `Y APPLY`，不要把左侧金额留在 0。HideVisual
的 collectionId 固定为 `2`，只有 type 18 Ready 才写入当前这件装备。已应用且无
待定时，右键该槽发 `Y CLEAR` 删除该件 FakeEntry（含隐藏外观，免费），不是隐藏
部位。外观跟物品实例走，换装不自动继承。账号方案列表以 type 19 为准；本机
SavedVariables 只用于可选的手动上传，登录不得自动灌库。手册物品页/套装页仍走
type 13/14。

幻化槽位 tooltip 是一条紧凑提示：品质色原装备名 + 军团/ez 幻化行。
Header 与外观名都用 `TRANSMOGRIFY_FONT_COLOR = 1, 0.5, 1`（粉）：
无待定写「幻化为:」，有待定只写「你将要幻化为:」，两行不并存。
隐藏条目写「隐藏」。不要 `SetInventoryItem`，那会把护甲/属性整段倒进同一条。
名称优先从 `GetInventoryItemLink` 的 `|h[名字]|h` 和 `|c` 品质色取出。
3.3.5 上 link 常因物品未缓存而为 nil，即使槽里穿着装备；此时用
`GetInventoryItemTexture` / `GetInventoryItemCount` / `equippedBySlot`
判断是否有装备，标题回退到 `GetItemInfo`、「物品 <id>」或槽位名。
官方空槽句「该装备栏里没有装备物品。」只在槽里确实没装备时出现，
不能把「未幻化」或「link 未缓存」当成空槽。未幻化只显示品质色原装备名，
不写「幻化为:」。3.3.5 没有 `GetInventoryItemID` / `SetTransmogrifyItem`
（若客户端提供了 `GetInventoryItemID` 可 and 回退）。
换装后若 itemId 对不上 type 18 绑定，不再写已应用那行。
纸娃娃/背包仍 hook `SetInventoryItem`，只在完整物品 tip 末尾追加同一套幻化行。

`SafeDressUp` 在 OnLoad 的 `SetUnit` 已就绪时只换装，不再 `ClearModel`。
`/reload` 触发的 `PLAYER_ENTERING_WORLD` 不得把预览锁在 alpha 0。

## 9. 验收清单

- 底部标签不是透明的。
- 选中标签有金色渐变。
- 左上圆环完整包住图标。
- 进度文本始终可见，绿色填充不越界。
- 搜索框没有明显拉伸边缘。
- 缩放 UI 或移动窗口后各控件仍保持相对位置。
- 各页共用同一搜索、过滤和进度组件。
- 幻化室 MoneyFrame 只显示最近一次 `U.copper`（0 铜也显示铜币），脏槽一次 `Y APPLY`。
