# 02 正式服风格公共 UI

## 1. 设计目标

3.3.5 没有正式服收藏日志模板，因此需要复用旧客户端可用的 Frame、Texture、StatusBar、EditBox 和 Dropdown，自行拼出正式服的结构。参考正式服时只复刻布局、层级和交互，不复制依赖新 API 的代码。

## 2. 主窗口结构

主入口是 `UI.CreateCollectionsFrame()`：

```text
主窗口
├─ 左上圆形分类图标
├─ 顶部标题
├─ 收藏数/总数
├─ 进度条
├─ 搜索框 + 过滤器
├─ 外观页专用“物品/套装”标签
├─ 内容宿主
└─ 窗口下方独立主标签
```

当前主窗口大小和锚点由 `CollectionsFrame.lua` 维护。内容宿主从窗口顶部约 122 像素开始，底部为悬挂标签保留空间。

## 3. 公共组件

### 九宫格和三段式纹理

边框不能把一张纹理直接拉满。`UI.ApplyNineSlice()` 将四角、四边和中心拆开；搜索框、标签和进度条适合使用三段式结构，固定两端，只拉伸中段。

### 底部标签

使用 `UI.CreateRetailBottomTab()`：

- 标签独立悬挂在主窗口下方。
- 未选中状态有深色实体填充。
- 选中状态显示金色渐变。
- 有完整边框、文字和悬停高亮。
- 相邻标签之间保留间距，不连接成一条透明栏。

切页统一调用 `UI.SetMainTab(key)`，不要直接在按钮回调中散落 `Show/Hide`。

### 搜索框

使用 `UI.CreateRetailSearchBox()`：

- 左侧搜索图标。
- 无输入时显示占位文字。
- 有输入时出现清除按钮。
- `OnTextChanged` 只修改查询并刷新活动页。
- 不在每次键入时重建整个主窗口。

### 过滤器

使用 `UI.CreateFilterPopup()`，各页面只提供过滤项：

- 已收集。
- 未收集。
- 偏好。
- 页面专属过滤项。

弹窗应在窗口隐藏或切页时关闭。

### 进度条

使用 `UI.CreateRetailProgressBar()`：

- holder 负责整体尺寸。
- StatusBar 的真实内容尺寸必须小于外框。
- 边框单独覆盖在前景层。
- 数字文字锚定到 StatusBar 中心。
- `SetProgress(collected,total)` 处理 total 为 0 的情况。

这样可以避免绿色填充越过边框，以及边框被横向拉伸。

### 收藏数量框

`UI.CreateCollectionCount()` 显示分类名称和数量。页面刷新时同时更新数量框和进度条，不能只更新绿色条而漏掉数字。

## 4. 左上圆形图标

正式服图标由三层组成：

1. 实际分类图标。
2. 圆形裁切/背景。
3. 完整金色圆环覆盖层。

图标与圆环必须同心，圆环尺寸略大于图标。不能使用方形图标加普通方框模拟。现有基础资源位于：

- `Media/Icons/mount-portrait.tga`
- `Media/Icons/launcher.tga`
- `Media/Icons/WardrobeSlots/slot-atlas.tga`
- `Media/Icons/WardrobeSlots/round-highlight.tga`

这些文件均由基础 AddOn bundle 发布；其格式、Hash 和来源由
`Media/assets.json` 约束。可选皮肤不得成为默认圆形图标或启动按钮的隐式
依赖。

## 5. 启动按钮

`UI.CreateLauncher()` 创建屏幕右下角收藏入口：

- 默认锚定右下角。
- 左键切换收藏日志。
- 左键拖动时移动按钮。
- 保存 point、relativePoint、x、y。
- `SetClampedToScreen(true)` 防止拖出屏幕。
- 提供 `UI.ResetPositions()` 恢复默认位置。

按钮使用正式服收藏图标和金色圆环，不使用临时背包图标。

## 6. 视觉状态约定

| 状态 | 推荐表现 |
|---|---|
| 已收集 | 正常亮度、金色名称或暖金细框 |
| 未收集 | 降低亮度、冷灰细框、可选小型“未收集”角标 |
| 已选中 | 2px 金黄色边框 |
| 鼠标悬停 | 全卡片轻微暖色 ADD 高亮 |
| 偏好 | 左上角金色星标 |
| 不可操作 | 按钮禁用并在 tooltip 说明原因 |

禁止用覆盖模型主体的大面积灰色矩形表现未收集，它会让卡片看起来像加载失败。

## 7. 新页面接入步骤

1. 创建页面 Frame 并填满 content host。
2. 设置 `scCategory`。
3. 实现 `Refresh()`、`SyncFilters()`、可选 `ClearSelection()`。
4. 在 `CollectionsFrame` 页面表和标签表注册。
5. 为页面设置标题、图标、数量名称。
6. 让搜索和过滤调用活动页方法。
7. 切页时关闭旧页面菜单并停止旧页面模型任务。

## 8. 验收清单

- 底部标签不是透明的。
- 选中标签有金色渐变。
- 左上圆环完整包住图标。
- 进度文本始终可见，绿色填充不越界。
- 搜索框没有明显拉伸边缘。
- 缩放 UI 或移动窗口后各控件仍保持相对位置。
- 各页共用同一搜索、过滤和进度组件。
