# 07 外观各部位镜头参数

## 当前实现

角色物品卡使用 `(raceId, sex, slot)` 选择 profile。九个 slot 为：

```text
HEAD SHOULDER BACK CHEST WRIST HANDS WAIST LEGS FEET
```

canonical profile 位于 `catalog/source/camera_profiles.json`，已批准的微调位于
`catalog/source/overrides/camera_profiles.json`，生成的 Lua 投影位于
`addon/SoloCollections/Data/Generated/CameraProfiles.lua`。当前基线覆盖基础
race/sex 页面，共 180 条 profile。

每个 profile 包含 stable `profileKey`、种族/性别、slot、M2 身份、sentinel、
vertical/horizontal、distance/minimum distance 和 yaw。sentinel
`0x5341..0x5349` 只声明身体部位；没有受支持的 SoloCam 时，后续原生
`SetCamera(1)` 保持安全 fallback。

## 差量而不是复制整表

真实客户端工作台保存相对 canonical profile 的差量：

```text
verticalOffsetDelta
horizontalOffsetDelta
distanceScaleMultiplier
minimumDistanceDelta
yawOffsetDelta
```

这样可以保留生成器从模型 bounds 得到的基础参数，也能明确看到人工贡献改变了
什么。未知 race/sex/slot、错误 profile hash 或越界数值会被拒绝。

## 构图目标

- `HEAD`：头盔完整，保留颈部和少量肩线。
- `SHOULDER`：主肩甲居中，另一侧不是主体。
- `BACK`：从背面观察，披风/背部主体完整。
- `CHEST`：领口到胸甲下沿完整。
- `WRIST`：腕部居中并保留少量手/前臂。
- `HANDS`：手套、手腕和部分前臂完整。
- `WAIST`：腰带中心与挂件有足够空间。
- `LEGS`：胯部到膝部，不把大腿塞满卡片。
- `FEET`：双脚和小腿下部完整。

## 修改流程

不要在本文保存某台电脑的截图路径。使用物品页内嵌“镜头工作台”导出
JSONL，再用 `tools/catalog/body_camera_tuning_import.py` 和
`body_camera_tuning_review.py` 生成 review-only 候选。审核通过后才更新
override source。

完整参数、截图要求、命令和 PR 模板见
[镜头参数贡献指南](../CAMERA_CONTRIBUTIONS.md)。

## 代码位置

- AddOn profile 应用：`addon/SoloCollections/UI/Wardrobe.lua`
- AddOn pose 归一化：`addon/SoloCollections/Core/M2Camera.lua`
- SoloCam 角色镜头：`client-extension/SoloCam/src/BodyCameraBridge.*`
- SoloCam profile 合同：`client-extension/SoloCam/src/CameraProfile.*`
- 生成和审核：`tools/catalog/character_camera_profiles.py`、
  `body_camera_tuning_import.py`、`body_camera_tuning_review.py`

编译成功不能证明构图正确。任何新增/修改 profile 都要保留真实 3.3.5a 客户端
的种族、性别、slot、分辨率、UI Scale 和修改前后截图。
