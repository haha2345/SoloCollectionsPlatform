# 07 外观各部位镜头参数

## 当前实现

当前物品卡直接使用 Transmorpher 3.0.0 的 Classic 预览 setup。护甲卡使用
`(raceFileName, sex, "Armor", slot)` 选择元组，九个 slot 为：

```text
HEAD SHOULDER BACK CHEST WRIST HANDS WAIST LEGS FEET
```

现行 Lua 数据位于 `addon/SoloCollections/Data/TransmorpherPreviewSetup.lua`，
包含 20 个基础种族/性别页的护甲 setup 和武器子类 setup。卡片适配器位于
`addon/SoloCollections/UI/EzWardrobe/Model.lua`。

护甲通过 3.3.5 原生模型 API 按 Transmorpher 顺序应用：reset、`Undress`、
`SetPosition`、`SetFacing`、原生 `TryOn`、`SetSequence`。模型 scale 保持 `1`，
`OnUpdateModel` 只恢复 sequence。护甲不依赖 SoloCam 哨兵；武器 TryOn 继续由
SoloCam v11 执行强制模型槽转换。

旧的 ezCollections Classic 镜头适配器已从活动树移除。canonical/override/
generated profile 和镜头工作台仍只作为历史调参资料；它们不驱动物品卡片。

## 历史差量资料

旧镜头工作台保存相对 canonical profile 的差量：

```text
verticalOffsetDelta
horizontalOffsetDelta
distanceScaleMultiplier
minimumDistanceDelta
yawOffsetDelta
```

这样可以保留生成器从模型 bounds 得到的基础参数，也能明确看到人工贡献改变了
什么。未知 race/sex/slot、错误 profile hash 或越界数值会被拒绝。

## 构图目标

- `HEAD`：头盔完整，保留颈部和少量肩线。
- `SHOULDER`：主肩甲居中，另一侧不是主体。
- `BACK`：从背面观察，披风/背部主体完整。
- `CHEST`：领口到胸甲下沿完整。
- `WRIST`：腕部居中并保留少量手/前臂。
- `HANDS`：手套、手腕和部分前臂完整。
- `WAIST`：腰带中心与挂件有足够空间。
- `LEGS`：胯部到膝部，不把大腿塞满卡片。
- `FEET`：双脚和小腿下部完整。

## 当前修改流程

不要在运行时叠加第二套镜头或逐帧修正。需要调整时，先在相同客户端、种族、
性别和 slot 上确认 Transmorpher 原 setup 的差异，再提交有明确来源和实机截图的
最小 override 设计。当前没有启用 override 层，旧工作台导出也不是现行卡片的
参数来源。

完整参数、截图要求、命令和 PR 模板见
[镜头参数贡献指南](../CAMERA_CONTRIBUTIONS.md)。

## 代码位置

- AddOn pose 归一化：`addon/SoloCollections/Core/M2Camera.lua`
- 历史 SoloCam 角色镜头：`client-extension/SoloCam/src/BodyCameraBridge.*`
- 历史生成和审核：`tools/catalog/character_camera_profiles.py`、
  `body_camera_tuning_import.py`、`body_camera_tuning_review.py`

静态检查不能证明构图正确。任何新增/修改 setup 都要保留真实 3.3.5a 客户端的
种族、性别、slot、分辨率、UI Scale 和修改前后截图。
