# 07 外观各部位镜头参数

## 当前实现

当前物品卡直接使用 ezCollections 的 Classic 镜头参数。角色物品卡使用
`(raceId, sex, slot)` 选择元组，九个 slot 为：

```text
HEAD SHOULDER BACK CHEST WRIST HANDS WAIST LEGS FEET
```

现行 Lua 数据和适配器位于
`addon/SoloCollections/Data/EzCollectionsCamera.lua`。这里只迁移 3.3.5a 使用的
Classic 表和 ezCollections 的 19 组武器镜头，不加载 HD2017/HD2019 分支。

镜头通过 3.3.5 原生模型 API 应用：`SetPosition`、`SetFacing`、
`SetModelScale` 和 `SetSequenceTime`。现行卡片路径不依赖 SoloCam 哨兵。

旧的 canonical/override/generated profile、SoloCam 桥和镜头工作台仍保留在
仓库中，作为历史调参资料和未来实验入口；它们不再驱动物品卡片。

## 历史差量资料

旧镜头工作台保存相对 canonical profile 的差量：

```text
verticalOffsetDelta
horizontalOffsetDelta
distanceScaleMultiplier
minimumDistanceDelta
yawOffsetDelta
```

这样可以保留生成器从模型 bounds 得到的基础参数，也能明确看到人工贡献改变了
什么。未知 race/sex/slot、错误 profile hash 或越界数值会被拒绝。

## 构图目标

- `HEAD`：头盔完整，保留颈部和少量肩线。
- `SHOULDER`：主肩甲居中，另一侧不是主体。
- `BACK`：从背面观察，披风/背部主体完整。
- `CHEST`：领口到胸甲下沿完整。
- `WRIST`：腕部居中并保留少量手/前臂。
- `HANDS`：手套、手腕和部分前臂完整。
- `WAIST`：腰带中心与挂件有足够空间。
- `LEGS`：胯部到膝部，不把大腿塞满卡片。
- `FEET`：双脚和小腿下部完整。

## 当前修改流程

不要直接改写来源区。需要调整时，先保留 ezCollections 原始元组，再在
`EzCollectionsCamera.lua` 的适配层增加有来源、有实机截图的最小覆盖。
旧工作台导出流程暂不作为现行卡片的参数来源。

完整参数、截图要求、命令和 PR 模板见
[镜头参数贡献指南](../CAMERA_CONTRIBUTIONS.md)。

## 代码位置

- 现行 Classic/武器镜头：`addon/SoloCollections/Data/EzCollectionsCamera.lua`
- AddOn 卡片应用：`addon/SoloCollections/UI/Wardrobe.lua`
- AddOn pose 归一化：`addon/SoloCollections/Core/M2Camera.lua`
- 历史 SoloCam 角色镜头：`client-extension/SoloCam/src/BodyCameraBridge.*`
- 历史生成和审核：`tools/catalog/character_camera_profiles.py`、
  `body_camera_tuning_import.py`、`body_camera_tuning_review.py`

编译成功不能证明构图正确。任何新增/修改 profile 都要保留真实 3.3.5a 客户端
的种族、性别、slot、分辨率、UI Scale 和修改前后截图。
