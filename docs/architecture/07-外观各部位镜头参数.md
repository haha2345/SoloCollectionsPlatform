Lua 在调用安全 fallback camera 前，通过特殊 camera index 声明部位：

| SHOULDER | `0x5342` | 正面左肩主体 |
| CHEST | `0x5343` | 颈部以下到腰部 |
| WRIST | `0x5344` | 右手腕 |

| WAIST | `0x5346` | 腰带和胯部 |

## 3. 当前 C++ 参数

`HumanFemaleCameraProfile` 参数顺序为：

```text
sentinel, verticalOffset, horizontalOffset,
distanceScale, minimumDistance, yawOffset
```

## 4. 各部位验收目标

### HEAD

- 正面。
- 头盔完整、模型居中并略向上。
- 显示颈部和少量肩线。
- 大型头盔顶部不能被裁切。

### SHOULDER

- 从角色正面观察。
- 角色左肩是主体并位于卡片中央。
- 另一侧肩甲、头发和躯干不是主体。
- 大型肩甲不能穿出卡片。

### CHEST

- 正面上半身。
- 胸甲从领口到下沿完整。
- 两侧袖口可作为参照。
- 若裁切过紧，优先增大 distanceScale，即“向后移”，不要改屏幕坐标。

### BACK

- yaw 为 π，从背后观察。
- 后颈、肩胛和披风主体完整。
- 武器和肩甲不应遮住披风。

### WRIST

- 右手腕居中。
- 显示少量前臂与手部。
- 目标偏低时增加 verticalOffset。

### HANDS

- 同时显示手、手腕和部分前臂。
- 手套必须完整，不只显示护腕。
- 与 WRIST 分开维护参数。

### WAIST

- 腰带中心位于卡片中央。
- 显示腹部下方和胯部上方。
- 长挂件有纵向空间。
- 穿模时先拉远，再微调 vertical。

### LEGS

- 显示胯部到膝部。
- 裤装和裙摆完整。
- 正式服参考比早期版本更远，不能把大腿放到充满整卡。

### FEET

- 两只鞋和小腿下部同时出现。
- 靴子位于卡片中下部。
- 给高筒靴和异形脚留出上方空间。

## 5. 调参流程

一次只调一个部位：

1. 让过滤器只显示目标部位。
2. 选择包含普通、小型和大型轮廓的3至6件装备。
3. 与正式服同部位截图对照。
4. 先调 `distanceScale` 控制整体远近。
5. 再调 `verticalOffset` 控制上下。
6. 再调 `horizontalOffset` 控制左右主体。
7. 只有背部等需要转向时才调 `yawOffset`。
8. 编译 DLL。
9. 用户截图验收。
10. 记录该种族和性别的最终参数。

不要同时修改 Lua scale、C++ camera 和模型矩形，否则无法判断哪个参数产生效果。

## 6. 编译与测试

```powershell
& '.\client-extension\SoloCam\scripts\build.ps1'
```

该脚本可通过 `SOLOCOLLECTIONS_VCVARS` 指定工具链，也可自动查找本机 Visual Studio Build Tools，并运行 `CameraProfileTests.exe`。

修改关键方向后应增加测试，例如：

- SHOULDER 必须从正面观察。
- BACK 的相机位置必须位于目标背面。
- 未知哨兵不能启用自定义镜头。
- 原生相机距离无效时必须安全失败。

## 7. 新增种族/性别

建议键使用 `(raceId, sex, slot)`：

1. 保留当前 Human Female 表。
2. 新建目标模型的九部位表。
3. 在 DLL 中可靠获取当前模型种族和性别。
4. 找不到 profile 时回退原生 camera 1。
5. 每个新 profile 先完成 HEAD、CHEST、FEET 三个锚点部位，再补其他部位。

禁止用人类女性参数强行覆盖全部模型。
