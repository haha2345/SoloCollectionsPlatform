# 分支怎么看

`main` 是合并后的平台树：`SoloCollections/`、`mod-solo-collections/`、`SoloClientSuite/`，并保留三个仓库各自 `main` 的完整提交历史。

旧仓库的功能分支按前缀放在本仓，目录布局仍是当时那个仓库的根目录（不是平台三分目录）：

| 前缀 | 来源 |
| --- | --- |
| `addon/*` | 原 SoloCollections |
| `module/*` | 原 mod-solo-collections |
| `suite/*` | 原 SoloClientSuite |

玩具箱 / 头衔页继续看：

- `addon/feat/deferred-toy-box`
- `addon/feat/deferred-title-journal`
