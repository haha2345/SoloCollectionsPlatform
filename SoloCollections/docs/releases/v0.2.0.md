# SoloCollections v0.2.0

SoloCollections `v0.2.0` is the first public source release using the separate
`mod-solo-collections` C++/SC2 backend as the sole production authority.

中文说明见下方；English release notes follow.

## 中文

### 推荐下载

下载 `SoloCollections-v0.2.0-unified-source.zip`。它包含：

- 可直接复制到 WoW AddOns 目录的 AddOn ZIP；
- 必须随 AzerothCore 编译的匹配模块源码 ZIP；
- `release-manifest.json` 版本与 commit 清单；
- 中英文安装、编译、使用和回滚文档；
- GPL/AGPL 与第三方声明；
- 内部文件 SHA-256。

同时下载 `RELEASE_SHA256SUMS.txt` 校验公开资产。只需要 AddOn 或模块源码时，
也可以下载对应的独立 ZIP。

### 怎么使用

1. 阅读包内 `README.zh-CN.md`。
2. 把模块解压到 `<AzerothCore>/modules/mod-solo-collections`。
3. 用 `MODULES=static` 重新运行 CMake 并编译 `authserver/worldserver`。
4. 配置 `SoloCollections.Backend = Cpp` 和
   `SoloCollections.Preview.Enabled = 1`。
5. 把 AddOn 解压到 `<WoW>/Interface/AddOns/SoloCollections`。
6. 启动后检查结构化日志，并执行 `.solocollections status`。

不要与旧 `v0.1.0` 的 ALE/SC1 服务端桥或旧目录混装。

### 发布边界

此 Release 不包含游戏 EXE、补丁 EXE、DLL、MPQ、DBC、M2/SKIN/BLP、WDB、
数据库或客户端提取素材。SoloCam 与独立武器资源由用户从自己有权使用的材料
本地构建。

### 已知问题

物品页镜头仍可能在部分种族、性别、HD/自定义模型和极端比例武器上出现过近、
过远、偏移或裁切。欢迎按仓库的镜头贡献指南提交参数和前后截图。

## English

### Recommended download

Download `SoloCollections-v0.2.0-unified-source.zip`. It contains:

- the runtime AddOn ZIP;
- the matching module source ZIP to compile with AzerothCore;
- `release-manifest.json` with exact commits and compatibility values;
- bilingual install, build, usage, and rollback documentation;
- GPL/AGPL and third-party notices;
- internal SHA-256 checksums.

Download `RELEASE_SHA256SUMS.txt` as well to verify the public assets. The
AddOn and module archives are also available separately.

### Quick use

1. Read `README.en.md` from the unified archive.
2. Extract the module to `<AzerothCore>/modules/mod-solo-collections`.
3. Re-run CMake with `MODULES=static` and build `authserver/worldserver`.
4. Set `SoloCollections.Backend = Cpp` and
   `SoloCollections.Preview.Enabled = 1`.
5. Extract the AddOn to `<WoW>/Interface/AddOns/SoloCollections`.
6. Check structured startup logs and run `.solocollections status`.

Do not mix this release with the ALE/SC1 bridge or catalog from `v0.1.0`.

### Distribution boundary

This release contains no game executable, patched executable, DLL, MPQ, DBC,
M2/SKIN/BLP, WDB, database, or client-extracted media. Build SoloCam and
standalone weapon resources locally from material you are entitled to use.

### Known issue

Item-page framing can still be too close, too far away, offset, or clipped for
some race/sex, HD/custom-model, and extreme-weapon combinations. Camera
parameter contributions with before/after screenshots are welcome.
